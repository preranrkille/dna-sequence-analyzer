# DNA Sequence Analyzer 🧬

A beginner-friendly Python project for analyzing DNA sequences.

## 📌 About the Project

This project was created as part of my learning journey in
Biotechnology and programming.

The program accepts a DNA sequence and performs basic sequence
analysis.

## 🔬 Features

- Validates a DNA sequence
- Calculates sequence length
- Counts A, T, G and C nucleotides
- Calculates GC content
- Calculates AT content

## 🛠️ Technology Used

- Python 3

## ▶️ How to Run

1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Open a terminal in the project folder.
4. Run:

```bash
python dna_analyzer.py
Enter a DNA sequence when prompted.
🧪 Example

Input:

The program displays:

Sequence length
A, T, G and C counts
